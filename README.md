# Аналитика интернет-магазина «Уютный дом»: рост, удержание, аномалия и A/B-тест

**Задача.** Магазин товаров для дома (2024–2025, ~45 тыс. клиентов, ~69 тыс. заказов) просит:
1) оценить динамику бизнеса; 2) понять, какие каналы приводят лояльных клиентов;
3) объяснить провал повторных продаж осенью 2025; 4) решить, раскатывать ли снижение
порога бесплатной доставки 3000 → 2500 ₽ по итогам A/B-теста.

**Стек.** SQL (SQLite: CTE, оконные функции, NTILE), Python (pandas, scipy, matplotlib).

## Ключевые выводы
| # | Вывод | Цифры | Рекомендация |
|---|---|---|---|
| 1 | Бизнес растёт, но держится на новых клиентах | Выручка 2025 — 128,2 млн ₽ (+52% к 2024); удержание M1 ≈ 8,9%, M6 ≈ 5,5% | Сместить фокус с привлечения на удержание |
| 2 | Каналы сильно различаются по качеству клиентов | Повтор за 90 дней: referral 32%, organic 27%, context_ads 17% | Перераспределить бюджет из контекста в реферальную программу; оценить CAC по каналам |
| 3 | Сентябрь 2025: обвал повторных заказов у marketplace_ads | 118 против среднего 248 за 3 мес. (−52%); другие каналы стабильны | Локальная проблема канала, не сезон → проверить кампании/фиды маркетплейсов за сентябрь |
| 4 | A/B-тест порога доставки **неинформативен** | Конверсия 3,24% vs 3,22% (p=0,89); чек −3,6% (p=0,08); ДИ разницы выручки на сессию [−13,9; +6,1] ₽ | Не раскатывать. Для MDE +4% нужно ~293 тыс. сессий на группу, было 30 тыс. → продлить тест или проверить более сильное изменение |
| 5 | «Под угрозой ухода» — 29,5% выручки | 9,4 тыс. клиентов, последняя покупка в среднем 476 дней назад | Win-back рассылка с персональным предложением; приоритет — категории Текстиль и Декор |
| 6 | Декор — самая маржинальная категория | Маржа 55,5% против 35% у Освещения | Использовать Декор в допродажах и промо |

## Структура
```
src/generate_data.py   генерация данных (seed=42, воспроизводимо)
src/analyze.py         SQL → CSV, графики, A/B-тест
sql/01..05_*.sql       запросы: KPI, когорты, аномалии (оконные функции), RFM, маржа
data/                  создаётся генератором (в репозиторий не входит)
output/                результаты запросов, графики, ab_test.csv
```
Запуск: `pip install -r requirements.txt` → `python src/generate_data.py` → `python src/analyze.py`.

## Проверка качества
- Сверка: сумма выручки по месяцам = сумме по категориям (доставленные заказы).
- Аномалия найдена правилом «отклонение > 35% от скользящего среднего за 3 мес.» — единственное срабатывание.
- A/B: z-тест долей, t-тест Уэлча, бутстрэп ДИ; дополнительно расчёт мощности.
